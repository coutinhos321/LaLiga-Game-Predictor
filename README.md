# LaLiga-Game-Predictor

This is a machine learning project created using the Random Forest Classifier model. 

The model uses historical data starting from 1995 to 2023 with the csv files downloaded from Kaggle (https://www.kaggle.com/datasets/kishan305/la-liga-results-19952020). 

The accuracy of the model is 0.78.
